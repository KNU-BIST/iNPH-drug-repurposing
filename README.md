# iNPH IFN-Activated Monocyte Signature — Computational Drug Repurposing

Computational pipeline supporting: *[manuscript title/citation — add on acceptance]*,
submitted to *npj Systems Biology and Applications*.

## Overview

This repository reanalyzes a public single-cell RNA-seq atlas of idiopathic normal
pressure hydrocephalus (iNPH; Duy et al. 2025, GSE292141) to identify a type I
interferon-activated classical monocyte subcluster, derive a 300-gene cell-state
signature, contextualize its magnitude against systemic lupus erythematosus, and
screen it against the LINCS L1000 perturbation database to nominate drug repurposing
candidates. Two primary leads (rosuvastatin, roflumilast) and one post hoc secondary
candidate (baricitinib) are reported; a Hallmark interferon-α gene-set sensitivity
analysis is included as an orthogonal check, framed explicitly as a sensitivity
analysis rather than independent validation.

This is a **computation-first study** (Phase A of a larger program). Wet-lab
validation (own-cohort scRNA-seq, flow cytometry) is planned as a separate,
subsequent phase and is not part of this repository.

## Repository structure

```
analysis/     Pipeline scripts, run in numeric order (see below)
R/            Sourced helper functions only (data_loading.R, clustering.R) —
              not run directly
data/raw/     Public input data (not tracked in git — see .gitignore)
data/processed/  Pipeline outputs (not tracked in git)
figures/      Generated figures — with_titles/ (full) and clean/ (publication)
Archived/     Superseded scripts and data from earlier pipeline iterations,
              kept for provenance only. DO NOT use anything in this folder to
              reproduce the manuscript — see ARCHIVE_LOG.csv for why each item
              was retired.
```

## Pipeline — run order

| Script | Purpose | Notes |
|---|---|---|
| `01_phase1_signature_derivation.R` | Pseudobulk DE (DESeq2), derives the 300-gene signature | |
| `02_lupus_benchmark.R` | Cross-disease contextualization vs. SLE (Perez et al. 2022) | Slow (~streams 307k monocytes in chunks); needs ~16 GB RAM headroom |
| `03_lincs_connectivity.R` | LINCS2 connectivity screen, candidate identification and tiering | Slow (gess_lincs(), 5–30 min); requires LINCS2 EH7297 (~4–8 GB, cached after first download) |
| `05_robustness.R` | Leave-one-out signature stability (promoted to a main-text result) | |
| `06_figures_all.R` | All main and supplementary figures | Builds its own standalone PBMC object for Supp Fig S1 on first run (slow; **not bit-reproducible** — see caveat below) |
| `08_numbers_audit.R` | Recomputes every reportable manuscript statistic from saved objects, including figure-file freshness checks | Run this to verify the pipeline reproduces the manuscript |
| `09_hallmark_ifn_positive_control.R` | Hallmark IFN-α sensitivity analysis (55 non-overlapping genes) | Independent LINCS2 query; slow for the same reason as 03 |

**There is no `04_*.R`.** Cell-line connectivity profiles (Figure 3, Supp Fig S5) are
generated by the `cellline_panel()` helper function defined inside
`06_figures_all.R`, not a standalone script.

One additional small script, run after 03:
- `build_full_597_csv.R` — exports the full ranked list of all 597 THP1 non-zero-connectivity
  compounds as `data/processed/supp_table3_full_597_compounds.csv` (connectivity metrics
  only; regulatory status/pharmacologic class were manually verified only for the top 30 +
  baricitinib, reported in the manuscript's Supplementary Table 3).

Note: an early draft used a separate `hallmark_supp_table.R` script to build the
Supplementary Table 4 compound summary from `09`'s output. That step is now built
directly into `09_hallmark_ifn_positive_control.R` (Section 6), so the standalone
script is redundant — if it still exists locally, archive it rather than run it, to
avoid the same "which version is canonical" ambiguity this project hit earlier with
duplicated figure and benchmark scripts.

## Environment

- R 4.5.3, Windows
- Key packages: Seurat, Harmony, DESeq2, AUCell, signatureSearch, ExperimentHub,
  rhdf5, here, dplyr, tidyr, ggplot2, patchwork, purrr, stringr, readr
- All scripts resolve paths via `here::here()`; no hardcoded drive letters.
  `INPH_EXTERNAL_DATA` is an optional environment variable for relocating the
  ExperimentHub cache — if unset, everything falls back to project-relative
  `data/raw/experiment_hub_cache`.
- 16 GB RAM is a hard constraint for `02_lupus_benchmark.R` specifically — it streams
  the Perez et al. lupus atlas in 10,000-cell blocks for this reason. Do not attempt
  to load the full lupus h5ad into memory at once.

## Reproducibility notes

- **Supplementary Figure S1 (PBMC UMAP/dotplot) is not bit-reproducible.** The
  standalone PBMC clustering and UMAP embedding built in `06_figures_all.R` involve
  stochastic steps (Louvain clustering, UMAP) that were not seeded in the original
  analysis. A fresh run will produce a visually similar but not byte-identical
  embedding, and cluster numbering may differ. Cell counts and the monocyte/other
  classification are reproducible; the exact 2D layout is not.
- **`08_numbers_audit.R` is the verification entry point.** It recomputes every
  number that appears in the manuscript text, tables, and figure captions directly
  from saved objects and flags any figure file that is older than the data it
  depends on. Run it after any pipeline change before treating results as final.
- The abandoned `targets` pipeline (a prior, different study design) is excluded
  from this repository entirely and is git-ignored where any trace remains locally.
