# Systems biology prioritizes drug candidates for interferon-activated monocytes in idiopathic normal pressure hydrocephalus

Reproducible computational workflow supporting the manuscript:

**Systems biology prioritizes drug candidates for interferon-activated monocytes in idiopathic normal pressure hydrocephalus**

Prepared for submission to *npj Systems Biology and Applications*.

## Overview

This repository reanalyzes publicly available single-cell RNA-sequencing data from patients with idiopathic normal pressure hydrocephalus (iNPH) to identify a type I interferon-activated classical-monocyte state and prioritize compounds predicted to reverse its transcriptional program.

The study has three primary computational stages:

1. **Cell-state signature derivation** — identification of the IFN-activated classical-monocyte subcluster and derivation of a 150-UP/150-DOWN (300-gene) pseudobulk differential-expression signature.
2. **Cross-disease contextualization** — comparison of the iNPH IFN state with interferon-high classical monocytes from systemic lupus erythematosus (SLE), with healthy-control donors included as a reference.
3. **Transcriptional connectivity analysis** — LINCS L1000/THP1 connectivity mapping to prioritize compounds predicted to reverse the iNPH IFN-associated transcriptional state.

The repository also contains leave-one-patient-out robustness analysis, a non-overlapping MSigDB Hallmark IFN-α pathway sensitivity analysis, main and supplementary figure generation, manuscript-number auditing, and table verification.

Rosuvastatin and roflumilast are treated as the primary computational candidates. Baricitinib is reported as a post hoc mechanistically aligned secondary candidate. These are **hypothesis-generating computational nominations**, not evidence of therapeutic efficacy in iNPH.

## Important: should `data/processed/` be empty for a fresh run?

**Yes.**

In the strict reproducibility workflow, `data/processed/` must be empty or
absent before the pipeline starts.

`00_prepare_canonical_monocyte_input.R` reconstructs:

```text
data/processed/duy_monocytes_classical.rds
```

from the public GSE292141 raw PBMC count matrices and the version-controlled
canonical cell-membership manifest.

The manifest preserves the exact historical 22,197-cell membership and order
used in the original analysis. It does **not** claim to independently
rediscover the original stochastic monocyte-cluster selection. This explicit
boundary allows the analysis-critical canonical population to be reconstructed
from public raw counts without distributing the former opaque prebuilt RDS.

### Safest fresh-run procedure

1. Clone the repository into a new directory.
2. Stage the required external/raw inputs under `data/raw/`.
3. Keep the version-controlled files under `data/canonical/` unchanged.
4. Leave `data/processed/` empty.
5. Leave generated figure directories free of stale outputs.
6. Run `renv::restore()` and confirm `renv::status()`.
7. Run `Rscript run_full_pipeline.R --preflight-only`.
8. If preflight passes, run `Rscript run_full_pipeline.R`.

The strict runner rejects pre-existing files in `data/processed/`, preventing
stale outputs from masking a failed reconstruction.

## Required input data

### 1. Canonical iNPH monocyte cell-membership manifest

Version-controlled inputs:

```text
data/canonical/duy_classical_monocyte_cell_manifest.tsv
data/canonical/duy_classical_monocyte_manifest_provenance.txt
```

The manifest records the exact 22,197 classical-monocyte cell identifiers and
their canonical order, together with patient, tissue, and MoCA-group metadata.
The provenance file documents the historical source and reconstruction
boundary.

The former prebuilt `data/processed/duy_monocytes_classical.rds` is **not** a
required starting input. Script 00 reconstructs it from the public GSE292141
raw PBMC matrices and validates the manifest before any downstream analysis.

### 2. GSE292141 iNPH PBMC/CSF data

Source: Duy et al. (2025), GEO accession **GSE292141**.

The PBMC raw count matrices are used by Script 00 to reconstruct the canonical 22,197-cell analysis input and are also used for the PBMC-level reconstruction underlying Supplementary Figure S1.

Expected location:

```text
data/raw/duy/extracted/
```

The helper `R/data_acquisition_and_loading.R` can download missing GSM-level supplementary files when a stable GEO connection is available.

### 3. Perez et al. SLE comparator atlas

Used for cross-disease contextualization.

Expected location:

```text
data/raw/perez2022_lupus/
    4118e166-34f5-4c1f-9eed-c64b90a3dace.h5ad
```

The cross-disease analysis streams this large file in blocks rather than loading the complete atlas into memory.

### 4. LINCS compound metadata from GSE70138

Expected location:

```text
data/raw/GSE70138_Broad_LINCS_pert_info.txt.gz
```

This file can be acquired programmatically from GEO by `R/data_acquisition_and_loading.R`.

### 5. CLUE/CMap compound metadata

Expected location:

```text
data/raw/compoundinfo_beta.txt
```

This file provides additional compound-name coverage. The current project documents it as a manual CLUE.io/CMap acquisition because a stable scriptable direct-download endpoint is not relied upon.

The optional companion Excel file may also be retained:

```text
data/raw/compoundinfo_beta.xlsx
```

### 6. LINCS2 L1000 signatures

The perturbational expression resource is obtained through Bioconductor **ExperimentHub accession EH7297** by the LINCS connectivity scripts. It is not stored directly under `data/raw/`.

### 7. Hallmark IFN-α gene set

The MSigDB `HALLMARK_INTERFERON_ALPHA_RESPONSE` set (systematic name **M5911**) is represented in the Hallmark sensitivity-analysis script. The sensitivity query excludes genes overlapping the primary iNPH signature before LINCS2 scoring.

## R environment

The analysis was developed and tested on Windows using R 4.5.x. The repository should be run using its locked package environment rather than by installing arbitrary current package versions.

From the repository root:

```r
install.packages("renv")
renv::restore()
```

Then check:

```r
renv::status()
```

The final reproducibility run should be performed only after `renv::status()` reports a consistent environment or any remaining differences have been reviewed.

The SLE contextualization stage is memory-intensive. A machine with approximately 16 GB RAM was used during development; the script streams the comparator atlas in blocks to reduce peak memory use.

## Automated reproducibility test

`run_full_pipeline.R` is the recommended entry point for final repository validation.

### Step 1 — preflight only

From a terminal opened at the repository root:

```text
Rscript run_full_pipeline.R --preflight-only
```

The preflight checks:

- all ten canonical analysis scripts;
- both helper files;
- R syntax parsing;
- required canonical, raw, and external inputs;
- non-empty input files;
- `renv.lock`, `.Rprofile`, and `.Renviron`;
- Git commit/working-tree information when Git is available;
- availability of the child `Rscript` executable.

No analysis is run in preflight mode.

### Step 2 — strict full run

If preflight passes:

```text
Rscript run_full_pipeline.R
```

The runner executes each analysis stage in a separate R process, stops at the first failure, verifies key expected output files, and by default requires those outputs to have been regenerated during the current run.

Logs are written under:

```text
logs/reproducibility/run_YYYYMMDD_HHMMSS/
```

including:

```text
pipeline_master.log
pipeline_summary.csv
runner_sessionInfo.txt
<one log for each analysis script>
```

For the final GitHub/submission reproducibility test, use the strict default mode rather than `--allow-existing-outputs`.

## Canonical analysis scripts

| Script | Purpose |
|---|---|
| `00_prepare_canonical_monocyte_input.R` | Reconstruct the locked 22,197-cell canonical monocyte analysis input from public GSE292141 raw counts using the version-controlled cell-membership manifest. |
| `01_derive_inph_ifn_signature.R` | Reconstruct the finalized monocyte subclustering and derive the 150-UP/150-DOWN iNPH IFN signature from the Script 00 canonical monocyte object. |
| `02_cross_disease_contextualization.R` | Compare the iNPH IFN state with SLE and healthy-control classical monocytes using AUCell as the primary scoring approach and mean-difference scoring as sensitivity analysis. |
| `03_run_lincs2_connectivity.R` | Run LINCS2 connectivity scoring, THP1-based compound ranking, candidate annotation, and candidate-tier generation. |
| `04_leave_one_out_robustness.R` | Recompute the pseudobulk signature after one-patient exclusion and quantify signature-level Jaccard stability and UP-gene persistence. |
| `05_generate_all_figures.R` | Generate all main and supplementary figures, including PBMC reconstruction for Supplementary Figure S1. |
| `06_audit_manuscript_results.R` | Audit key reportable manuscript quantities and figure/data consistency. |
| `07_hallmark_ifn_sensitivity.R` | Run the non-overlapping Hallmark IFN-α pathway sensitivity query against LINCS2. |
| `08_export_full_thp1_compound_ranking.R` | Export the complete ranked set of 597 compounds with non-zero THP1 connectivity. |
| `09_verify_manuscript_tables.R` | Verify computational values used in the manuscript and supplementary tables. |

## Supplementary Figure S1 and the canonical monocyte population

The PBMC-level UMAP used in Supplementary Figure S1 is reconstructed from the public GSE292141 PBMC files. The exact 22,197 classical monocytes used in the downstream manuscript analyses are **not redefined by the new PBMC clustering**. Instead, their canonical cell identifiers are mapped onto the reconstructed PBMC embedding.

The reconstruction uses explicit clustering and UMAP seeds for the current repository workflow. Nevertheless, the reconstructed PBMC UMAP is not expected to be pixel-identical to historical embeddings generated under earlier software/session conditions. The canonical monocyte cell membership used for the downstream analysis remains fixed.

## Reproducibility boundaries

The repository reconstructs the analysis-critical 22,197-cell canonical
classical-monocyte input from public GSE292141 raw count matrices using a
version-controlled cell-membership manifest.

The important historical boundary is the **selection of those cell
identifiers**. The original PBMC Harmony/clustering workflow did not preserve a
complete seed/software state sufficient to guarantee independent stochastic
rediscovery of exactly the same 22,197 cells. The manifest therefore freezes
the historical membership and order rather than pretending to rederive that
selection de novo.

Once the manifest-defined population is reconstructed, the raw count matrix,
gene and cell ordering, required metadata, and downstream Script 01 results
have been validated against the former canonical object. The public
reproducibility claim should therefore state that the workflow reconstructs
the locked analysis population from public raw counts plus the canonical
manifest and then regenerates the downstream analyses.
